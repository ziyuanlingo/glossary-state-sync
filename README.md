# @ziyuanlingo/glossary-state-sync

**Cross-Chapter Terminology State Table & Selective Recall Engine for ZiyuanLingo Document Translation Pipelines**

Official open-source state synchronization library powering [ZiyuanLingo Cloud](https://ziyuanlingo.com) (`EN / 中文 / 日本語`).

## Overview

Maintains versioned 3-tier terminology state tables (`locked`, `preferred`, `forbidden`) updated via incremental JSON patches across 400+ page academic monographs, patent filings, and cross-border legal contracts, recalling only exact active spans per chapter chunk.
